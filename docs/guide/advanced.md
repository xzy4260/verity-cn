# 高级自定义配置

完成 [网站初始化配置](/guide/config) 后，你还可以在游戏内对 Verity 进行更深入的自定义。

进入方式：**游戏主界面 → 点击「Mod」→ 选择「Verity-cn」→ 点击下方「配置」按钮**，即可进入配置界面。

配置界面分为 **通用 / 修改 / 个性化 / LLM·TTS·STT / 账户** 五大板块。

---

## 通用

通用里的配置可自行根据需要更改，例如各项功能的开关、基础行为参数等。如无特殊需求，保持默认即可。

---

## 修改（Verity 行为修改）

本板块包含对 Verity 行为的修改，主要有以下三项：

### 击杀村民

控制 **Verity 是否会击杀村民**。关闭后 Verity 不会对村民产生敌对行为。

### 友好模式 ⭐ cn 版独有

开启后，Verity **不再输出任何恐怖内容，同时不再变身恶魔形态**，旨在真正成为你的游戏助手。

> ⚠️ 此功能仍处于 **beta 阶段**。若你在使用过程中发现问题或有改进建议，欢迎到 [GitHub 提交 Issues](https://github.com/xzy4260/verity-cn/issues) 或在 QQ 群内反馈。

### 使用老版物品给予机制

此项由 **@埋藏心底的悲伤** 提出并强烈请求。在高版本中，原作者几乎移除了 Verity 给予物品的能力；此项旨在**恢复该能力**（使用老版机制）。

---

## 个性化

### 自定义人设

你可以在这里输入想要的**人设**，可规定名字、性格等，**没有硬性模板限制**，自由发挥即可。

### 皮肤

支持自定义皮肤。使用方法：

1. 在 `.minecraft/config/verity/skins` 目录放入自定义皮肤文件：

   ![config/verity/skins 目录](/images/guide/skins-folder.png)

2. 皮肤文件应为 **`.zip` 格式**，内部包含 **16 张变体 png 图片**（不包含箱子图片）。
3. 放好后**重新打开配置界面**即可在皮肤选项中选择。

## LLM / TTS / STT

LLM、TTS、STT 三者各自拥有**独立的功能开关**，可自由开关。

三者也都带有 **「启用 Verity Mod 配置」开关**：

- **开启（默认）**：所有 AI 请求走 [Verity Mod 网站](https://veritycn.site/)（即你在网站上配置好的通道）。
- **关闭**：走下方的「自定义路线」，由你在游戏内自行填写接口信息。

### LLM

标准的 **OpenAI 兼容协议**。关闭「启用 Verity Mod 配置」后，自行填写 Base URL、API Key、模型名即可。

### TTS

关闭「启用 Verity Mod 配置」后，使用 **TTS 模式**：

- **内置 TTS（默认）**：可编辑它的音色。
- **Base URL 模式**：走自定义 OpenAI 兼容 TTS。
  - 对小米的接口做了兼容（小米的接口**不是**规范的 OpenAI TTS 接口）。
  - 除常规的 OpenAI 信息外，还需填写**音色**。
  - 针对小米 TTS 做了**流式响应支持（仅小米有效）**，**建议开启**。
- **MiMo 音色克隆模式**：
  - 需选择 MiMo 的 Base URL 端点：**按量付费** 或 **Token Plan**（当前不能自定义）。
  - 填写相关信息后，可使用**内置克隆音色**，也可使用**自定义克隆音频**。
  - 自定义音频请放在 `.minecraft/config/verity/sample_audio` 目录：

    ![config/verity/sample_audio 目录](/images/guide/sample-audio-folder.png)

  - 放好后**重新进入配置界面**即可选择。

### STT

关闭「启用 Verity Mod 配置」后，支持 **本地识别** 与 **Base URL** 两种模式。

### 本地 AI 支持与 Base URL 填写规范

只要你关闭对应 AI 的「启用 Verity Mod 配置」开关，走自定义路线，就**可以接入本地部署的 AI**：

- 在对应的 **Base URL** 里填你本地部署的标准 **OpenAI 兼容接口**地址即可（例如本地跑的 Ollama、vLLM、LM Studio、One API 等暴露的 OpenAI 兼容端点）。LLM、TTS、STT 各自独立，需要哪个就填哪个。
- 如果你的模型/服务**没有暴露标准 OpenAI 兼容接口**，可以**让 AI 帮你写一段本地中转脚本**（在本地起一个小服务，把你的私有接口「翻译」成 OpenAI 兼容格式），再把中转脚本的地址填进 Base URL 即可。

> ⚠️ **Base URL 只填「基础地址」，不要填完整补全地址！**
>
> 后端会自动在 Base URL 后面拼接 `/chat/completions`、`/audio/speech` 等具体路径。因此：
> - 一般填到版本前缀即可，常见以 **`/v1`** 结尾（如 `http://127.0.0.1:11434/v1`、`https://api.openai.com/v1`）。
> - **不绝对**：请自行判断。例如 **智谱**（Zhipu/GLM）的兼容接口是以 **`/v4`** 结尾，应填 `https://open.bigmodel.cn/api/paas/v4`。
> - **不要**写成完整补全地址（例如 `.../v1/chat/completions`、`.../v1/models`）。如果填了完整路径，后端会再拼一次，变成 `.../v1/chat/completions/chat/completions`，直接请求失败。

## 账户（Verity Mod 账户）

账户板块即 **Verity Mod 账户**管理：

- **登录失效**：点击 **「OAuth 登录」** 重新登录。
- **更改了网站的模型 / 音色 / 其他信息**：点击 **「刷新」** 同步最新配置。
- 可在此**再次进行连通性检测**。
- 可**退出登录**。

> 💡 注意：这里的所有操作在**成功得到结果后，会自动重新打开配置界面以刷新结果**。
