# AI 错误码参考

当你与 Verity 对话、语音合成或语音识别时，请求会经过 **Verity Mod 网站（代理）** 或直接到达 **上游 AI 服务商**（如 DeepSeek、豆包、OpenAI、小米等）。当任意一环出错时，游戏内或连通性检测中会返回 HTTP 状态码。

下面按类别整理常见错误码的含义与处理建议。

> 💡 看到错误码时先判断来源：若你开启了「启用 Verity Mod 配置」，问题多在 **网站代理层**；若走自定义 Base URL，则问题多在 **你的接口填写** 或 **上游服务商**。

---

## 4xx — 客户端 / 请求类错误

通常由「密钥、权限、地址、参数」引起，重试一般无效，需要你主动修正配置。

| 状态码 | 名称 | 常见原因（Verity 语境） | 处理建议 |
|--------|------|------------------------|----------|
| **400** | Bad Request | 请求参数缺失或格式错误；自定义接口填写的 JSON 不合法 | 检查 LLM/TTS/STT 各项填写是否完整，确认模型名、音色等字段正确 |
| **401** | Unauthorized | API Key 无效、缺失或已过期 | 到网站上重新添加 / 刷新密钥；走自定义路线时检查 Key 是否复制完整 |
| **402** | Payment Required | **余额不足或未付费**（常见于 DeepSeek / 豆包付费通道） | 到对应服务商充值；或改用网站上的免费通道（稳定性不保证） |
| **403** | Forbidden | 密钥无权限、被封禁，或区域 / IP 受限 | 确认账户状态正常；付费通道检查是否开通对应模型权限 |
| **404** | Not Found | 模型不存在、URL 路径错误（如 Base URL 漏写 `/v1`）、模型名拼错 | 确认 Base URL 以 `/v1` 结尾；核对模型名称与服务商一致 |
| **408** | Request Timeout | 请求在规定时间内未完成（多为网络或上游慢） | 稍后重试；检查网络质量 |
| **409** | Conflict | 并发请求冲突（少见） | 稍后重试 |
| **413** | Payload Too Large | 发送的内容过大（如过长的上下文 / 音频） | 缩短对话历史或音频长度 |
| **422** | Unprocessable Entity | 参数语法合法但语义错误（如填写了接口不支持的字段） | 检查自定义接口参数，移除不支持的字段 |

---

## 429 — 限流

| 状态码 | 名称 | 常见原因 | 处理建议 |
|--------|------|----------|----------|
| **429** | Too Many Requests | 触发了服务商的**速率限制 / 每分钟请求数上限** | 暂停片刻后重试；降低连续请求频率；免费通道尤其容易限流，建议用付费通道 |

---

## 5xx — 服务端 / 网关类错误

通常由「服务端临时故障、过载、维护」引起，**多数可重试**，与你的配置无关。

| 状态码 | 名称 | 常见原因（Verity 语境） | 处理建议 |
|--------|------|------------------------|----------|
| **500** | Internal Server Error | 上游服务商或网站代理内部出错 | 稍后重试；若持续出现，到 QQ 群或 GitHub 反馈 |
| **502** | Bad Gateway | 网关错误（代理 / Verity Mod 网站后端异常、上游无响应） | 稍后重试；检查网站状态，或在账户页点击「刷新」 |
| **503** | Service Unavailable | 服务不可用 / 过载 / 维护中 | 等待服务恢复后重试；免费通道更易出现 |
| **504** | Gateway Timeout | 网关等待上游响应超时 | 稍后重试；检查网络与上游状态 |
| **529** | Too Many Requests（过载别名） | 部分服务商用 529 表示服务端过载（类同 429） | 退避后重试，降低请求频率 |

---

## 排查建议

1. **先看是否开启了「启用 Verity Mod 配置」**：
   - 开启 → 优先在 [Verity Mod 网站](https://veritycn.site/) 检查密钥、模型、代理通道是否正常，并在游戏内账户页点击「刷新」。
   - 关闭 → 优先检查你填写的 **Base URL（是否带 `/v1`）**、**API Key**、**模型名**、**音色** 是否正确。
2. **跑一次连通性检测**：在账户页点击连通性检测，根据返回的状态码对照上表定位。
3. **区分免费 / 付费通道**：`402 / 429 / 503` 多出现在免费通道，建议切换到 DeepSeek / 豆包的付费通道。
4. **仍无法解决**：到 [GitHub 提交 Issues](https://github.com/xzy4260/verity-cn/issues) 或在 QQ 群（@xzy4260：`1057631803` / @涓星向凡：`1076577219`）反馈，并附上具体的错误码与截图。
