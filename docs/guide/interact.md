# 与 Verity 交互

当配置全部通过、连通性检测无误后，就可以进入游戏，与 Verity 正常交互了。

## 召唤 Verity

1. 创建一个世界并进入，会有**纸箱**在玩家附近生成。
2. **右键**打开纸箱，Verity 会从中出来。
3. 你可以用**右键**将其转为**物品形态**带在身上。

## 与 Verity 对话

- **文字对话**：当 Verity 以**实体形态存在**时（非物品栏持有的物品形态），直接在聊天栏输入消息即可与其对话。
- **语音对话**：长按 `V` 键即可进行语音对话。

> ⚠️ 若 `V` 键与其他模组按键冲突，请打开 **「选项 → 按键控制 → 按键绑定」** 进行调整。

至此，你已完成 Verity-cn 的全部配置与基础交互。享受与 Verity 的陪伴吧！
