# Verity-cn

Minecraft AI 伴侣模组的中文本地化与 Android 适配版本。

为国内玩家优化：内置中文对话、语音合成/识别、网易云音乐集成、免费 LLM 接口，开箱即用。

## 功能

- AI 对话与记忆系统
- TTS 语音合成 / STT 语音识别
- 网易云音乐播放与歌词同步
- 首次启动配置向导
- 支持 PCL2、HMCL、BakXL 等主流启动器
- Java 17 / 支持 Android
